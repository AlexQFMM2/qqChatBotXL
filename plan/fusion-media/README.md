用户要求在现有 Fusion 编辑弹窗的「工具」区统一管理扩展，像识图一样选择模型。此前 QQ/微信绘图、改图和语音使用环境变量；旧克隆 TTS 在当前千问入口不可用，新 Qwen Audio 使用不同接口。不能据旧入口错误断言整个平台下架。真实生图曾成功，但产物超过微信 5 MiB 限制。

本轮复用 Fusion Profile metadata、模型选择器、现有 Provider 凭据和微信传输。增加渠道绘图、改图、语音配置项和鉴权执行接口；模型配置在 CCR 唯一持有，QQ/微信按请求使用，不复制凭据。渠道扩展由机器人根据用户请求执行，不能伪装为尚未实现的内部 MCP 工具。原搜索、B站和视觉工具保持现有职责。

语音模型和音色分开选择；保留现有已登记夏莉音色与绑定型号，不擅自替换。首版语音/改图执行支持现有千问原生协议，绘图复用兼容聊天接口；候选菜单不承诺所有文本模型能生成音频。模型真实可用性仍需实际请求验证。歌曲模型、原生微信语音气泡、文件共享继续延期。

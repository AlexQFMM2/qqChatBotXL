## 用户已确认的方向

- 继续现有 `qqChat` 共用核心与 CCR/Fusion，不迁移 AstrBot、NapCat、DSH 或 OpenClaw。微信通过已实现的 iLink 协议适配直接接入，无需运行 OpenClaw。
- “主控大脑 + 识图、绘图、语音、联网、文件工具”：主模型按消息和上下文决定调用什么，程序负责权限、预算、执行及真实结果。不要恢复用绘图/语音关键词提前分流的方案。
- 画面涉及夏莉自己时，主模型自主选择夏莉参考图；不要要求用户特意说“使用参考图”。普通场景不用角色参考，结合用户图片和夏莉形象时使用两者。
- 模型和音色在 CCR 后台统一选择，更换后用于后续请求；不在机器人另建一套供应商配置。保留夏莉人格和参考音，不擅自换成普通音色。
- 跨渠道延续的是授权长期记忆。当前上下文、聊天库和私有工作区仍按渠道及会话隔离；不把全部聊天拼到一个上下文，不导入旧聊天，不自动共享文件。

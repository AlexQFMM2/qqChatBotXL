# 实施任务

执行模式：单执行者串行；Owner / 集成负责人：Codex。所有任务在 qqChat 仓库内，不启动并行代理。

## B0 / T-001：计划与规范

- 输入：用户确认的完整计划、现有 bot / LLM / voice 实现。
- 输出：本目录 README、任务台账及目录索引；固定六个文字栏目和五个英文验收样本。
- 依赖：无；并行候选：否。
- 验收：目标、权限、接口、发布与回滚边界完整记录。
- 共享资源：plan/catalog/README.md；交接：以 README 的 Status 为准。

## B1 / T-002：解读核心

- 输入：T-001 规范。
- 文件：app/word_learning.py、app/prompts/word_learning.md、tests/test_word_learning.py。
- 输出：工具 schema、不可变卡片数据、严格校验和固定排版；单词仅英文词，可含撇号/连字符，结构错误不会发卡片。
- 依赖：T-001；并行候选：否。
- 验收：缺失、未知字段、错误类型、超长、控制标记、常见词/构词/多词性样本验证。
- 共享资源：后续 bot 的卡片接口；交接：给 T-003 传递工具及渲染接口。

## B2 / T-003：双端接入

- 输入：T-002 卡片与规则。
- 文件：app/bot.py、app/llm.py 及对应测试。
- 输出：终结型工具结果兼容 Anthropic / OpenAI；工具按模型判断触发；程序发送完整卡片后复用语音，普通成员文字可用，语音继承当前权限。
- 依赖：T-002；并行候选：否。
- 验收：无二次模型改写、无表情/闲聊尾声、无截断；每轮至多一条读音；发送失败、撤销、纯文字及禁用路径符合规范。
- 共享资源：主控/工具循环/发送序号，必须串行；交接：完整针对性测试结果。

## B3 / T-004：验证与文档

- 输入：T-003 实现与针对性测试。
- 文件：tests/、scripts/ 单词预检脚本、README.md、docs/controller-tools.md。
- 输出：完整应用回归、模拟平台的真实主模型预检、可试听音频、使用说明与剩余事项。
- 依赖：T-003；并行候选：否。
- 验收：自动化全部通过；真实样本内容核验、英文发音试听分别记录。未试听不能写成已通过。
- 共享资源：实际模型/TTS 配额；交接：命令、样本结果、音频位置、准确的未完成项。

## B4 / T-005：发布验收

- 输入：T-004 验收证据、固定候选版本及上一镜像。
- 输出：发布版本、双端健康、用户主动发起的手机验收记录。
- 依赖：T-004；并行候选：否。
- 验收：QQ / 微信文字完整、语音可播放且顺序正确；无重复发送；记录镜像及回滚方法。
- 共享资源：生产 QQ / 微信容器，串行发布；交接：未发布/未手机验收时保持待办，不标记总计划完成。

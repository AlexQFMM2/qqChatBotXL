## 问题与目标

现有 PersonaBot 共用 QQ / 微信人格、主模型工具循环与语音适配器，但没有结构化单词解读工具，也不自动加载 SKILL.md。新增“解读 unhappy / 讲讲 reusable 这个单词”：程序输出单词、英美音标、翻译、对应词性、构词拆解和一条中英例句，然后附夏莉声音的单词读音。

## 已确认决策

- 默认附单词读音；用户说“只要文字”时跳过。文字面向可聊天成员，语音保持渠道开关与真实身份权限。
- 规则独立保存并显式加载；主模型选择 submit_word_card，程序校验与排版。新增最终工具结果，结束两种兼容协议的工具循环，避免二次改写。
- 一次一个英文词，可含连字符或撇号；拼写错误建议确认，不静默改词；多词、短语和混合任务提示拆开。
- 无法确认的音标明确标注；词源与记忆联想分开，无可拆结构时直说，不硬编词根。模型讲解不冒充词典核验。
- 语音只读单词，复用现有模型、音色、预算及 SILK / WAV 链路，不承诺精确英美口音或音素控制。
- 先文字后语音，文字失败不合成；合成失败保留文字并提示；渠道发送结果不明立即停止，不自动重发。保留身份、脱敏、撤销检查与去重。
- 不新增词典 API、服务、数据库、通用技能框架或供应商配置。后续词典查询可在单词卡片结构之前提供证据。

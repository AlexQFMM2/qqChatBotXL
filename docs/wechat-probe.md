# 微信最小回路测试（G0）

这个入口验证 iLink 扫码、文字、图片和文件传输。回复是固定测试提示，**尚未接入夏莉、模型或工具**。使用独立状态目录，不读取 QQ 配置或启动 QQ 服务。

## 现在开始

本机已准备 `.venv-wechat`，在终端执行：

```bash
cd /home/alexqfmm/workPlace/MyModelApp/qqChat
./scripts/wechat-probe.sh
```

首次运行会显示二维码，同时生成 `.wechat-probe/login.png`。用你自己的微信扫码并在手机确认；如果要求验证码，在这个终端输入手机显示的数字。凭证由程序保存，无需复制 Token。二维码过期会自动刷新，最多两次；成功或停止后删除二维码文件。

之后在微信中打开扫码连接的机器人会话，按顺序测试：

| 操作 | 应看到的结果 |
|---|---|
| 发 `测试` | 收到“文字收发成功”和测试说明 |
| 发一张小 PNG / JPEG / GIF / WebP 图片 | 收到大小与哈希说明，以及回传图片 |
| 分别发小 TXT / PDF / XLSX 文件 | 收到说明与回传文件；可下载后核对 SHA-256 |
| 发 `延迟 120`，两分钟内不再发消息 | 约两分钟后收到使用原请求上下文的回复 |
| 可选：发 `延迟 300`，五分钟内不再发消息 | 约五分钟后收到回复；用户已决定本轮跳过 |
| 发 `结束测试` | 收到结束提示，本机进程退出 |
| 再运行同一脚本，重新发 `测试` | 直接复用凭证，验证重启续用，无需再次扫码 |

默认最多 12 个测试请求、20 分钟；附件上限 5 MiB、图片上限 2000 万像素。这些是诊断限制，不代表微信服务上限。一次发一个附件；测试期间发送的图片和文件都会被当作往返样本。普通闲聊不触发回复，`帮助` 与 `/测试` 也可查看测试提示。

延迟指令也接受 `延迟120`、多个空格、全角空格或全角数字。延迟测试不会先回复确认，避免改变待测条件；本机终端会显示开始与实际等待秒数。手机实际收到才算成功，HTTP / 业务成功不能代替人工验收。回传图片可能被微信压缩，文件内容可按哈希核对。

## 停止、重启与排错

- 终端 `Ctrl+C` 或微信发 `结束测试` 都可停止。保留账号与游标，下一次运行同一脚本继续。
- 查看本机登录状态：`./scripts/wechat-probe.sh status`；凭证失效时重新扫码：`./scripts/wechat-probe.sh login`，随后运行测试脚本。
- “已有微信诊断进程”表示旧进程仍在运行，应先停止旧进程。同一状态目录只允许一个进程；不要复制账号文件另开轮询器。
- 收到“回复结果不明”时，在手机核对；程序保留记录并停止，不自动重发。需要再次验证时，重启脚本并从手机发一条新测试消息。
- “跳过旧消息或缺少时间戳”时，在当前测试窗口发送新消息。诊断只处理启动前五秒至当前窗口内、具有完整消息状态和时间戳的测试请求。
- 网络错误在终端显示脱敏原因。诊断不通过代理环境变量，直接访问微信 HTTPS；陌生主机、私网解析地址和 HTTP 重定向会被拒绝。

这是受控协议测试：游标在整批处理后保存，发送前记录请求，未完成请求不自动重跑。它没有正式业务的持久收件箱；重启后会跳过旧测试消息，不能当作生产消息无丢失保证。正式恢复语义由后续 T-007 实现。

## 环境与数据

在其他 Linux 主机重建环境（Python 3.12）：

```bash
uv venv .venv-wechat --python python3.12
uv pip install --python .venv-wechat/bin/python -r requirements-wechat.txt
./scripts/wechat-probe.sh
```

可用 `WECHAT_PYTHON=/绝对路径/python ./scripts/wechat-probe.sh` 指定已有环境。QR 依赖只在 `requirements-wechat.txt` 中，QQ 镜像不增加此依赖。

默认状态在 `.wechat-probe/`：目录 700，凭证 `account.json` 与游标 / 请求结果 `probe.json` 为 600。附件仅在内存中做受限传输，不落盘、不执行或解析文件内容；诊断结果不存原始聊天或上下文令牌。状态目录与虚拟环境均已加入 Git / Docker 忽略规则，勿把凭证或二维码放进交接文档。

协议依据腾讯官方 `@tencent-weixin/openclaw-weixin@2.4.10`；Python 代码为本项目独立实现。当前只验证开发机网络，生产服务器出站链路、真实扫码和手机收发结果须分别记录。

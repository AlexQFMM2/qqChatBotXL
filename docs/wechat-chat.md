## 启动

以下为未迁出测试账号的本机入口。**现有账号已迁到服务器，默认目录会拒绝启动；不要删除迁出标记绕过保护。** 新测试状态须使用独立账号和目录。

```bash
./scripts/wechat-chat.sh --check  # 仅做一次模型连接测试，不收发微信
./scripts/wechat-chat.sh          # 持续运行，Ctrl+C 停止
```

也可用 `--minutes 30` 限定本次运行时长。诊断与聊天入口共用一个账号锁，不能同时启动。无需重新扫码；登录失效后先停止聊天，再使用 `./scripts/wechat-probe.sh login` 重登同一账号。

默认读取 `.env`、私有 `.wechat-probe/model.env`、`.wechat.env`，后面的文件覆盖前面的值，已有 shell 环境优先。不执行配置中的 shell 表达式。`.wechat.env.example` 仅供参考，不含凭证。微信不要求 QQ 凭证；本机凭证已从现有服务器配置只读取得，受限保存在 `.wechat-probe/model.env`，不打印、不提交。

服务器实例为 `wxchat-bot`，使用 Compose `wechat` profile、自动重启和独立持久目录 `wechat-data/`，没有公开端口。关闭开发机不影响服务器接收。健康详情在 `wechat-data/health.json`；登录失效会停止轮询等重新登录。回到本机前必须先停服务器并同步最新状态，不能使用旧游标或旧聊天库。

## 直接使用

- 文字：直接聊天，不用 @；`/help`、`/status`、`/reset` 可用。`/reset` 只清本次私聊上下文，保留文件。
- 长期记忆：`/memory` 查看用法，`/memory list 关键词` 查看授权事实；支持记住、纠正、遗忘、共享和撤销。`/reset` 不删除长期记忆。共享文件本轮延期。
- 后续看图：可以说“再看刚才那张图片”或“看看那张照片”，使用本次会话最近一条含图消息；清空上下文后不再引用旧图。
- 附件：图片 / 文件先校验和下载到本次私聊工作区，再进入同一套模型与工具；每个附件最多 5 MiB。`/files` 查看，`/read 相对路径` 读取 UTF-8 文本或 XLSX，`/send 相对路径` 回传。
- 生成：现有文本 / PDF 工具、Fusion 识图和已配置的生图 / 改图路径已接线。发送 PDF 不等于模型已经能读取 PDF；当前 `read_file` 原生支持文本和 XLSX，PDF 解析没有因此新增。
- 表情：复用仓库 `bq/` 中的 9 张夏莉表情，容器内回退到 `emotes/`；可用 `WECHAT_EMOTE_PATH` 覆盖路径，`EMOTE_ENABLED=false` 关闭。已修复本机默认路径错误并启用，沿用人格中约每 2～3 轮自然选择一张的引导，不强制固定频率。表情按图片单独发送，内部标记不展示。
- 防止自回复：只接收绑定用户发给机器人的完整用户消息，拒绝机器人发出的文字和图片；发出的表情也不成为“最近上传的图片”。用户主动把表情发回来时，才作为一次图片请求处理，同一入站消息去重。
- 当前微信未启用 SearXNG 联网工具、B 站适配器、原生语音、主动早安。实际能力以 `/status` 和配置为准。

代码复用不等于所有媒体效果已经真实验收：本轮自动验证了图片进入视觉路径、TXT / XLSX 读取、文本生成回传、下载失败提示；指定格式逐项手机体验、生成图 / PDF / 表情、完整引用语义和共享服务容量仍在计划内。

## 同一核心，分开的当前会话

```text
QQ 官方事件 ──→ QQ 解析 ───────┐
                             ├→ IncomingMessage → PersonaBot → 同一 Fusion / 工具
微信长轮询 ──→ 可信身份与落盘 ─┘                         ↓
                                       QQTransport / WeChatTransport → 原会话
```

QQ 保留原库和目录，目标容器已升级共用版本。微信服务器运行库为 `wechat-data/chat.db`，工作区为 `wechat-data/workspace/<会话哈希>/`，备份为 `wechat-data/backups/`。两端复用 `MemoryStore` / `GroupWorkspace`，原聊天与文件仍独立；`shared-memory/` 提供经过授权的长期事实和定期摘要。授权文件共享明确延期，不会自动公开私有文件。

## 收件与恢复

同一批合法入站消息与新游标在 SQLite 同事务保存；重复消息去重，最多积压 100 条，满后不推进游标并退避。收件和单工人处理独立运行，模型慢请求不会堵住收件。首次启用聊天不回复此前诊断期间的旧消息；之后重启保留未处理消息。

已开始的任务重启后不自动重做，避免重复写文件或付费生图；使用原入站上下文尝试发送一次中断提示。发送前落发送记录，成功后保存确认；网络超时或崩溃期间的发送标记为结果不明，不自动重发或继续工具操作。原上下文过期时提示也可能无法送达，需要用户发新消息继续；下一有效入站汇总历史异常的交互尚待完善。

完成请求后移除收件 payload，避免长期保存 CDN 密钥与回复上下文；聊天历史和工作区按现有维护规则清理。备份可能含未完成请求的敏感状态，必须与账号凭证一样保护，不可公开分享整个状态目录。

共享记忆和常驻实现后，本地及服务器候选完整回归 264 项通过（包含原 228 项）；实际表情送达和逐格式体验仍保留后测。验证：`PYTHONDONTWRITEBYTECODE=1 .venv-wechat/bin/python -m unittest discover -s tests -v`。完整门槛和观察进展见 [交接](../plan/wechat-private-chat/handoff.md)。
